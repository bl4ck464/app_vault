About APKVault


An independent, backend-free Android app store built for the open web.

MISSION

Why APKVault exists

APKVault was created to give independent Android developers a home. Most app stores are controlled by large corporations with opaque review processes, mandatory fees, and arbitrary rules. We believe there is a better way.

Our store is 100% static — no backend, no database, no tracking. It runs on GitHub Pages and anyone can fork, modify and self-host. This is app distribution the way it should be: open, transparent and developer-first.

PRINCIPLES

What we stand for

Security

Every app is reviewed for safety. Malware and spyware have no place here.

Openness

The platform is open-source. Fork it, host it, make it yours.

Transparency

No hidden tracking, no secret algorithms. What you see is what you get.

Community

Built by developers, for developers. Community-driven and community-first.

ARCHITECTURE

How it works

APKVault is a pure static site. There is no backend, no server, no database and no build step. The entire store consists of:

  • index.html — the store front page with search, filters and app grid
  • app.html — detail page template (content injected by script.js)
  • distribution.html — distribution policy
  • about.html — this page
  • style.css — all styles (dark theme, lime accent, responsive)
  • script.js — app logic, search, filters, sort, mobile menu, scroll reveal
  • app.json — the app catalog (data source)

Deploy it to GitHub Pages, Netlify, or any static hosting. That is all there is to it.

Built different.

No backend. No tracking. No corporate gatekeeping. Just apps and the open web.
